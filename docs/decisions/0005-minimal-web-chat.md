# 0005 - Minimal web chat

## Decision

The first chat interface uses FastAPI as the RAG backend and Streamlit as a thin HTTP
client. Answers are generated by a tiny local `transformers` model and must include
Milvus-backed citations.

## Context

The project already has ingestion, cleaning, chunking, embeddings, and Milvus indexing.
The next useful slice is an end-to-end user loop, while keeping business logic out of
the UI and keeping CI free from live Milvus and model downloads.

## Consequences

- FastAPI owns retrieval, prompt construction, generation, and response contracts.
- Streamlit only renders chat messages and citations.
- Unit tests use fake retrievers and fake generators.
- If retrieval returns no context, the assistant answers that it does not know and
  points users to official sources.
